# Agentic CLI Tab Logos

Drop SVG brand assets into this folder using these exact filenames:

- `codex.svg` — OpenAI Codex CLI
- `claude.svg` — Claude Code
- `devin.svg` — Devin CLI
- `cursor.svg` — Cursor CLI
- `antigravity.svg` — Antigravity CLI

If an icon file is not present yet, `web/src/tab-label.ts` gracefully hides the broken `<img>` and displays a styled monogram badge instead.
