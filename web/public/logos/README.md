# Tab Logos & Brand Attribution

SVG brand logos in this directory identify locally running shells and AI coding CLIs in session tabs:

- `codex.svg` — OpenAI Codex CLI (trademark of OpenAI)
- `claude.svg` — Claude Code (trademark of Anthropic)
- `devin.svg` — Devin CLI (trademark of Cognition Labs)
- `cursor.svg` — Cursor CLI (trademark of Anysphere, Inc.)
- `antigravity.svg` — Antigravity CLI (trademark of Google LLC)
- `powershell.svg` — PowerShell (trademark of Microsoft Corporation)
